# Portfólio de Edição de Vídeo — Math (@quatrocentavos)

Portfólio minimalista, direto e moderno focado em edição de documentários, ensaios visuais e produções audiovisuais.

## 🚀 Como testar localmente
Basta abrir o arquivo `index.html` em qualquer navegador (dê 2 cliques nele ou use o Live Server no VS Code).

## 🛠 Como personalizar seus vídeos e dados
Abra o arquivo [`script.js`](./script.js):
1. **Vídeos**: Altere o array `PROJECTS` com o título, duração, descrição e o `youtubeId` (o código que fica depois de `v=` no link do YouTube).
2. **Contato**: No objeto `CONFIG`, atualize seu e-mail e número de WhatsApp.

## 🌐 Como hospedar na Vercel
1. Crie um repositório no seu GitHub com esses arquivos (ou use o CLI da Vercel).
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New... > Project"**.
3. Conecte seu repositório.
4. Por ser um site estático puro (HTML/Tailwind/JS), você **não precisa configurar nada** no build. Basta clicar em **Deploy**!
